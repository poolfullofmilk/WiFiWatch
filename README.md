# Wifi Watch

Tells you if your connection is fine, and when it wasn't, where it went wrong.

![Incidents](Screenshots/Incidents.png)

![History](Screenshots/History.png)

## Features
- Live status of your Wi-Fi, router and internet
- Logs every problem and says where it was: Wi-Fi, home network, provider or DNS
- Notifies you only when something serious happens or lasts
- Warns when radar pushes your router off a DFS channel
- History, speed tests and a report for your provider

## Quick start
1. Download the exe from the [latest release](https://github.com/poolfullofmilk/WifiWatch/releases/latest)
2. Run it and turn on location services if asked

## ⚠️ Important
- Needs Windows 11 in English with location services on

## Technical details
- .NET 10, WPF with Blazor, MudBlazor and SQLite
